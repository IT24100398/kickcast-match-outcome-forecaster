# ⚽ KickCast – Match Outcome Forecaster

**A Machine Learning-Based Football Match Outcome Prediction System**

## 📌 Project Overview

KickCast is a sports analytics project that predicts football match outcomes using historical data from the European Soccer Database.

The system classifies match results into three categories:

- **Home Win**
- **Draw**
- **Away Win**

It uses machine learning algorithms to analyse historical match data and generate outcome predictions with probability estimates.

## 🎯 Project Objectives

- Analyse historical European football match data.
- Develop machine learning models to predict match outcomes.
- Compare the performance of different classification algorithms.
- Visualise prediction probabilities and model performance.
- Provide an interactive dashboard for exploring match predictions.

## 🧠 Machine Learning Models

Four classification algorithms were implemented and evaluated:

1. Logistic Regression
2. Random Forest
3. Decision Tree
4. XGBoost

The models were evaluated using classification performance metrics, including accuracy and macro F1-score.

## 📊 Dataset

**Source:** European Soccer Database

- 25,979 football matches
- 11 European leagues
- 8 seasons (2008/09–2015/16)

The dataset contains historical football match information used for model development and evaluation.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Machine Learning:** Scikit-learn, XGBoost
- **Data Analysis:** Pandas, NumPy
- **Visualisation:** Matplotlib, Seaborn
- **Dashboard:** Streamlit
- **Development Environment:** Google Colab

## 🚀 Key Features

- Predict football match outcomes.
- Display probabilities for Home Win, Draw, and Away Win.
- Compare the performance of four machine learning models.
- Explore match-related insights through an interactive dashboard.
- Visualise model evaluation results.

## 📈 Project Findings

- Random Forest was selected as the recommended working model.
- Logistic Regression provides a simpler alternative.
- Predicting draws remains challenging due to the nature of football match outcomes.
- Models incorporating betting odds achieved better predictive performance.
